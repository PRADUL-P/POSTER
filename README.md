# Moon Day Quiz Winners Poster Maker (ചാന്ദ്ര ദിന ക്വിസ് വിജയികൾ)

A fully responsive, highly interactive web application designed to customize and generate celebration posters for the Moon Day Quiz. 

## Features
- **General Info Customizer:** Edit the poster title and school name in real-time.
- **Dynamic Winners Configuration:** Add or remove winners for First, Second, and Third prize categories. The layout automatically adapts (grids adjust dynamically).
- **Position & Zoom Tuning:** Slide controls to scale and pan individual winner pictures, adjust name text offset vertically, and align text (left/center/right).
- **Custom Backgrounds:** Upload custom poster backgrounds, and adjust dimming overlays or blur filters for high readability.
- **Print & PDF Export:** Clean print layout template that hides the customizer control panel and centers the high-resolution poster card for a quick print or "Save as PDF".

## Running Locally
Double-click `index.html` or run a local HTTP server inside the folder.
